# Flower-3

Браузерное приложение для эволюционного обучения нейронной сети игре в футбол.

## Запуск

```bash
cd /home/aminadav/Projects/Flower-3
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000` в браузере.

## Возможности

- визуализация матчей на поле 110×68 метров;
- управление параметрами популяции и архитектуры сети;
- медленный и быстрый режим обучения;
- показ и скрытие матчей;
- эволюционный подбор особей по фитнес-функции.
